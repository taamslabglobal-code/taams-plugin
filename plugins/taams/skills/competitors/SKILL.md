# TAAMs 경쟁 구도 분석


분석 대상 품목(사용자 입력, 미확정): $product_name
아래 1단계 `search_products` 로 반드시 정확한 한글 품목명을 확정한 뒤 진행한다.
품목명이 주어지지 않았다면 사용자에게 무엇을 볼지 먼저 묻는다.

개별 도구의 데이터 규칙은 각 도구의 설명이 정본이다. 이 프롬프트는 호출 순서·분기·결과 배치만 다룬다.

호출 순서
1. search_products 로 정확한 한글 품목명을 확정한다.
2. get_product_importers 로 그 품목을 들여오는 국내 수입사와 건수를 본다.
3. get_product_trend 로 같은 품목의 기간별 수입 추이를 본다 — 지금의 구도가 굳어진 것인지 최근에 바뀐 것인지는 추이 없이는 말할 수 없다.
4. 사용자가 '어디서 들여오나'까지 물으면 get_product_top_exporters 를 더한다.

분기
· 2단계가 0건이면 **없다고 답하지 말 것.** 품목명이 통관 표기와 다를 때 흔히 0건이 된다(예: '새우' 0건 → '냉동흰다리새우살' 92개사). 1단계 결과의 다른 이름으로 다시 시도하고, 그래도 없을 때에만 없다고 답한다.
· truncated=true 면 상위 일부만 받은 것이다. 총계는 total 을 쓰고, 순위를 '전체 순위'라고 말하지 않는다.

결과 조합·배치
· 같은 수입사가 국가별로 여러 줄에 나뉘어 온다. 업체 단위로 합쳐 보여 주고, 국가 구성은 그 업체의 조달처 분산으로 따로 말한다.
· 상위 몇 개사가 얼마를 차지하는지(집중도)를 먼저 말하고, 그다음 개별 업체를 나열한다 — 나열만 하면 구도가 보이지 않는다.
· 조회 기간을 반드시 함께 밝힌다. 기간이 다르면 순위가 달라진다.

말하지 말 것
· **건수를 시장점유율·매출로 바꿔 말하지 말 것.** 이 도구가 주는 cnt 는 통관 건수이지 물량도 금액도 아니다. 한 건의 크기는 제각각이다.
· 특정 업체를 '1위 수입사'라고 단정하지 말 것 — 이 품목명, 이 기간 기준의 건수 순위다. 그 조건을 함께 말하지 않으면 사실이 아닌 문장이 된다.

(참고) 도구가 등급 제한·한도 초과로 정책 응답을 돌려주면(예: error='grade_required') 그 message 를 그대로 전달할 것 — 오류로 재해석하지 않는다.
